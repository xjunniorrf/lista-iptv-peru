# Lista IPTV Perú

Lista M3U con canales peruanos que transmiten gratis desde sus propias fuentes oficiales.
Los enlaces se tomaron del proyecto iptv-org: https://github.com/iptv-org/iptv (archivo streams/pe.m3u).

## Cómo usarla

Copia esta URL en tu reproductor IPTV (VLC, IPTV Smarters, TiviMate, Kodi):

https://raw.githubusercontent.com/xjunniorrf/lista-iptv-peru/main/lista.m3u

## Canales

ATV, ATV+, ATV Sur, Latina, Latina Noticias 24/7, Latina Clásicos, RPP TV, TV Perú, Exitosa TV, Cultura 24, JNE TV y América Internacional.

Algunos canales no transmiten las 24 horas o pueden dejar de funcionar si la fuente cambia.
